# Welcome to Your Django Project!

## Getting Started

- The `Workspace: Start Dev` task starts Django and Tailwind in grouped integrated terminals.
- VS Code asks once whether to allow automatic tasks for this folder. Allow it to start the task on open, or run `Workspace: Start Dev` from the Tasks menu.

## Dev Startup Scripts
- `start-dev.sh` (macOS and Linux) and `start-dev.bat` (Windows) open this folder in a new VS Code window.
- Both need the `code` command on your PATH.

## Admin Setup
- `README.md` explains how to create a Django superuser.

## Project Structure
- `manage.py` - Django management script
- `templates/` - HTML templates
- `static/` - Static files
- `my_shop/` - Django project configuration
