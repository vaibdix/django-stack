# my-shop

Generated by [django-stack](https://github.com/vaibdix/django-stack).

## Prerequisites

- Python 3.13 or newer
- [uv](https://docs.astral.sh/uv/) for dependency management
- Node.js and pnpm, to build the Tailwind stylesheet

## Setup

```bash
uv sync
[ -f .env ] || cp .env.example .env
pnpm install
pnpm run build:css
uv run python manage.py migrate
uv run python manage.py createsuperuser
uv run python manage.py runserver
```

No superuser is created for you. Run `createsuperuser` above, then sign in at
`/admin/`.

`.env.example` ships a placeholder `SECRET_KEY` so the project boots immediately.
Replace it before you deploy anything:

```bash
uv run python -c 'import secrets; print(secrets.token_urlsafe(50))'
```

## Styles

Tailwind compiles `assets/tailwind.css` into `static/dist/styles.css`, scanning the
templates and the Python files that carry classes. Keep it rebuilding while you work:

```bash
pnpm run watch:css
```

The compiled stylesheet is committed, so a deploy needs no Node. Run
`pnpm run build:css` and commit the result whenever templates change.

## Environment

`ENVIRONMENT` is the only switch for `DEBUG`. Set it to `local`, `test`, `staging`
or `production`; `DEBUG` is on for `local` and `test`. Everything that behaves differently in development — the browsable
API, plain-text logging, the browser-reload endpoint — reads that one value.

Configuration is validated at startup by `my_shop/conf.py`.
A missing or malformed variable stops the process with a message naming the field
rather than failing later at the point of use.

## Tests

```bash
uv run python manage.py test --settings=my_shop.settings.test
```

The suite needs no `.env`, so it runs the same in a fresh clone and in CI: `settings.test` sets `ENVIRONMENT=test`, which supplies a throwaway `SECRET_KEY` that no other environment accepts.

## Deployment

```bash
export DJANGO_SETTINGS_MODULE=my_shop.settings.production
uv sync --no-dev --frozen
uv run --no-dev python manage.py migrate --noinput
uv run --no-dev python manage.py createcachetable
uv run --no-dev python manage.py collectstatic --noinput
uv run --no-dev python manage.py check --deploy
uv run --no-dev gunicorn my_shop.wsgi:application --bind 0.0.0.0:8000
```

Static files are served by WhiteNoise, so no separate web server is required for
them. `check --deploy` warns that HSTS covers neither subdomains nor the preload
list: set `SECURE_HSTS_INCLUDE_SUBDOMAINS` and `SECURE_HSTS_PRELOAD` to `True` once
every subdomain serves HTTPS, because leaving the preload list takes months. Set
`TRUST_PROXY_SSL_HEADER=True` only behind a proxy that overwrites
`X-Forwarded-Proto`. Set `DEFAULT_FROM_EMAIL` to an address your mail server
sends from: production refuses Django's default, `webmaster@localhost`. Copy `.env.production.example` to `.env` on the server and fill it in.

`manage.py` defaults to `settings.local` and gunicorn to `settings.production`. Export
`DJANGO_SETTINGS_MODULE` before running management commands on a server: it is read before
`.env`, so it has no effect there. `settings.local` refuses to start unless `ENVIRONMENT=local`,
and `settings.production` refuses to start with it.

## Layout

| Path | What lives there |
|------|------------------|
| `my_shop/` | settings, URLs, WSGI/ASGI and the health check |
| `my_shop/settings/` | `base.py`, `local.py`, `production.py`, `test.py` |
| `catalog/models.py` | the model, its queryset and its database constraints |
| `catalog/fields.py` | the ISBN field and the rules every write path (forms, admin, API) shares |

| `catalog/templates/` | the pages for this app |

| `static/` | CSS and JavaScript |
| `assets/tailwind.css` | Tailwind input; compiled to `static/dist/styles.css`, kept out of `static/` so `collectstatic` never sees it |

## API access

The API is read-only for anonymous callers: `GET` works without signing in, and
writes need an authenticated user. Sign in at `/api-auth/login/` and the browsable API shows the create
and edit forms. To make the demo API writable without signing in, set
`DEFAULT_PERMISSION_CLASSES` to `rest_framework.permissions.AllowAny`.
